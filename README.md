# 約好 Yuehao — 美業與工作室的線上預約 SaaS

給美髮、美甲美睫、教練、工作室的多租戶預約系統。店家三分鐘開好預約頁，客人自己選服務與時段；店家以月訂閱付費。

## 功能

**客人端**（`/b/店家代稱`，手機優先）
- 選服務 → 指定或不指定人員 → 選時段 → 留姓名手機，不必註冊
- 預約明細頁可加入行事曆、自行改期或取消

**店家後台**（`/dashboard`）
- 總覽：今日預約、本月營收、新顧客、未到率、營收走勢、熱門服務、新手引導清單
- 預約：完成／未到／取消／復原、改期、手動新增、CSV 匯出
- 週行事曆、顧客名單（來店次數、消費、備註、匯出、刪除個資）
- 服務項目、服務人員（各自提供哪些服務、每週固定休假）、營業時間、臨時公休、預約規則
- 店家設定：預約頁資訊、QR Code、品牌色、改密碼、兩步驟驗證、刪除帳號
- 使用說明：後台內的常見問題
- 方案與帳單：月繳或年繳、升級、換方案、取消與恢復訂閱、付款紀錄

**營運後台**（`/admin`，僅 `ADMIN_EMAILS` 內的帳號）
- 月經常性收入、店家數、付費轉換率、活躍店家
- 每間店的用量、停權、手動調整方案
- 收款紀錄、資料庫大小與備份、管理操作稽核

**系統**
- 收款：綠界信用卡定期定額（台灣）或 Stripe；扣款失敗有 3 天寬限期
- 通知：新預約、取消、改期、前一天提醒（所有方案）、店家每晚的明日預約摘要、付款成功與扣款失敗、額度將滿、信箱驗證、忘記密碼
- 自動化：每日備份與加密的異地備份、過期資料清理、訂閱到期降級、終止扣款的自動重試、新店家引導信、給營運者的異常通知與每週摘要
- 防護：三層限流、內容安全政策、簽章驗證的金流回呼

| --- | --- | --- |
| 免費版 | NT$0 | 1 位人員、每月 30 筆線上預約（超過仍會收單，但要升級才看得到客人的聯絡方式）、前一天 Email 提醒、頁尾有品牌標示 |
| 專業版 | NT$499 | 5 位人員、預約不限、營收分析、匯出、品牌色、移除品牌標示 |

## 本機執行

需要 Node.js 22.13 以上，不需另外安裝資料庫。

```bash
npm install
npm run dev                      # http://localhost:3000，首頁可一鍵進示範店家
npm run check                    # 型別檢查 + 單元／整合測試 + 建置
npm run build && npm run e2e     # 瀏覽器端對端測試（需要 Playwright）
```

開發環境沒設金流時，升級按鈕會直接切換方案（示範模式）；沒設寄信時，信件內容印在終端機。要看營運後台，設 `ADMIN_EMAILS=你的Email` 後用該 Email 註冊，再開 `/admin`。

## 驗證狀態

- 35 個單元／整合測試、81 項瀏覽器端對端檢查全數通過
- Docker 映像的執行階段實際跑過（以非 root 執行、健康檢查、root 擁有的資料磁碟可寫、重啟後資料仍在）
- 綠界簽章演算法通過官方三組測試向量；結帳表單與回呼流程以模擬方式測過
- **尚未用真實服務驗證**：綠界測試環境的實際刷卡、Resend 實際寄信、Stripe。上線前請照 [docs/deployment.md](docs/deployment.md) 的檢查表各跑一次
