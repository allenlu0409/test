# 驗收清單

照順序走一遍，大約 30–40 分鐘。每一項寫的是「做什麼」和「應該看到什麼」。

## 準備

```bash
npm install
npm run build
npm run preview        # http://localhost:3000
```

`npm run preview` 會建立驗收用的資料並啟動伺服器。預覽環境和正式環境有三個差別：

- **不收款**：升級按鈕直接切換方案（示範模式）。真正的綠界流程要部署後用測試卡驗證。
- **不寄信**：系統產生的信都列在 `/dev/mail`，信裡的連結可以直接點。
- **管理者不強制兩步驟驗證**：方便你直接進營運後台。正式環境會強制。

| 帳號 | 密碼 | 用途 |
| --- | --- | --- |
| `admin@yuehao.test` | `yuehao-2026` | 營運後台 `/admin`，同時是「驗收測試店」的店家 |
| `lin@yuehao.test` | `yuehao-2026` | 付費店「小林美甲」（專業版） |
| `cheng@yuehao.test` | `yuehao-2026` | 免費店「阿成理髮」，本月額度已用 26／30 |

要重來一次：停掉伺服器，刪除 `data/preview.db*`，再跑 `npm run preview`。

## 一、首頁與第一印象

- [ ] 開首頁。主視覺是一頁預約本，上面有螢光筆標記和紅色印章；整體沒有大圓角卡片和膠囊按鈕。
- [ ] 用手機寬度看一次（瀏覽器開發者工具切成手機）。沒有橫向捲動，文字不會被切掉。
- [ ] 按「先看示範店家的後台」。不用註冊就進到一間有資料的店，上方有「這是示範店家」的提示。

## 二、開店（店家）

- [ ] 登出，按「免費開始」註冊一個新帳號。
- [ ] 填店名、選行業、取網址。網址填 `demo` 會被拒絕（保留字）。
- [ ] 進到後台：看到「預約頁開好了」、新手引導清單，服務項目已經依行業建好。
- [ ] 上方有「還沒確認信箱」的提示。開 `/dev/mail`，點歡迎信裡的連結，提示消失。

## 三、客人預約（請用手機寬度）

- [ ] 從後台按「開啟預約頁」。選服務 → 選日期 → 選時間 → 填姓名手機 → 確認。
- [ ] 完成後畫面蓋上「約好了」的印章。
- [ ] 按「加入行事曆」會下載 `.ics` 檔。
- [ ] 按「改時間」，選另一個時段，回到明細頁顯示新的時間。
- [ ] 回到預約頁再約同一個時段：已經被訂走的時間不會出現。
- [ ] 開 `/dev/mail`：有「新預約」（給店家）和「客人改期」的信。預約時有填 Email 的話，還有一封「預約成功」給客人。
- [ ] 回到明細頁按「取消預約」，要按第二次確認才會取消。

## 四、每天使用（店家）

用示範店家或 `lin@yuehao.test` 登入，資料比較多。

- [ ] **總覽**：今日預約、本月營收、新顧客、未到率排成一條；下面有營收長條圖和熱門服務。
- [ ] **預約**：對一筆今天的預約按「完成」和「未到」；對未來的預約按「改期」。
- [ ] **手動新增預約**：建立一筆；再對同一位人員同一時間建立一次，應該被擋下。
- [ ] **行事曆**：切換上週、下週。
- [ ] **顧客**：搜尋姓名；點開一位寫備註；按「刪除這位顧客的個人資料」。
- [ ] **服務項目**：新增、編輯、下架一項。下架後客人的預約頁上看不到它。
- [ ] **服務人員**：取消勾選某人的一項服務；勾選一個固定休假日。到預約頁確認：選那項服務時看不到他，他休假那天標示「休」。
- [ ] **營業時間**：把某一天設成公休，新增一個臨時公休日。預約頁上那兩天不能選。
- [ ] **店家設定**：改店家介紹；看到 QR Code，可以下載。
- [ ] **使用說明**：每一題都點得開，內文的連結會帶到對應的頁面。

## 五、方案與升級

用 `cheng@yuehao.test` 登入（免費版、額度快滿）。

- [ ] 總覽上方有「本月線上預約已用 26 / 30 筆」的提醒。
- [ ] 服務人員頁：不能新增第二位，出現升級提示。
- [ ] 顧客頁的「匯出 CSV」標示為專業版功能。
- [ ] 方案與帳單：三個方案排成價目表。切到「年繳」，價格變成 10 個月的金額。
- [ ] 按「升級專業版」。回到服務人員頁，現在可以新增；CSV 可以下載。
- [ ] 回帳單頁改回免費版。資料都還在。

## 六、帳號安全

- [ ] 登入頁按「忘記密碼」，輸入信箱。到 `/dev/mail` 點重設連結，設定新密碼。同一條連結再開一次會顯示已失效。
- [ ] 店家設定 → 兩步驟驗證 → 開始設定。用手機的驗證器 App 掃 QR Code，輸入 6 位數，畫面顯示 8 組備用碼。
- [ ] 登出後只用密碼登入會被擋；展開「我有開啟兩步驟驗證」輸入驗證碼才能進。
- [ ] 店家設定最下方「刪除帳號」：要輸入密碼和店家代稱。刪除後那間店的預約頁變成找不到。

## 七、營運後台

用 `admin@yuehao.test` 登入，開 `/admin`。

- [ ] 看到每月經常性收入、店家數、付費轉換率、活躍店家。
- [ ] 店家列表裡有你剛剛註冊的店。點開一間，用「手動方案」改方案（要填原因）。
- [ ] 對一間店按「停權」。它的預約頁顯示「目前暫停線上預約」；再按一次解除。
- [ ] 按「立即備份」和「下載最新備份」。
- [ ] 最下方的管理操作紀錄列出剛剛做的事。
- [ ] 用別的帳號（例如 `lin@yuehao.test`）開 `/admin`：顯示找不到頁面。

## 八、影片

- [ ] `marketing/out/` 裡有三支 Reels 和一支使用影片；`marketing/out/preview/` 有可以直接看的 GIF 和分鏡圖。
- [ ] 每支從頭播一次，確認節奏和文案。全部沒有配樂。

## 預覽環境驗不到的部分

這些要等部署並接上真實服務之後才能驗，步驟在 [deployment.md](deployment.md)：

- 綠界實際刷卡（月繳、年繳、取消、扣款失敗）
- 信件真的寄到信箱
- 預約前一天的提醒、新店家引導信、異常通知與週報（由排程在特定時間寄出，預覽環境裡不容易等到）
- 每日異地備份（GitHub Actions）

自動化測試涵蓋了上面多數流程的邏輯：`npm run check` 與 `npm run e2e`。
